# EC-APP-1 — design v2 (7 ottobre 2026)

Commit this folder as `docs/azm-deliverables/EC-APP-1/design-v2/`. It is the design input for `EC-APP-1-PR2`…`PR5`.

- `png/` — every screen at 2× (780 px wide). Visual reference.
- `source/*.html` — the source of each screen: exact Italian copy, sizes, colours, fonts. Open in a browser; it renders standalone. Copy is taken from here, never re-typed from the PNG.
- Figma (same screens + route/T04 cards + frame 35 navigation note): https://www.figma.com/design/lVw7TvOd7c9EbfQpcs0COt

Photos are Easy Casa brand stills, not listing data. `[x]`, `[min]`, `[max]`, `[anno]`, `[numero]`, `[id]` are holes for real data. Prices come from the catalogue API, never from these files.
